## 🎨 设计系统应用

### 色彩系统（温暖橙色主题）

| 用途 | 颜色值 | 应用场景 |
|------|--------|----------|
| **主色** | `#FF6B35` | 按钮、选中状态、强调元素 |
| **主色深** | `#E65100` | 按下状态、深色强调 |
| **主色浅** | `#FFE5DC` | 背景、选中背景 |
| **主色极浅** | `#FFF0E8` | hover、辅助背景 |
| **背景** | `#FFF5F0` | 页面主背景（温暖米白） |
| **次要背景** | `#FFE8E0` | 卡片、区域背景 |
| **文字主** | `#2C1810` | 标题、正文（深棕色） |
| **文字次** | `#8B6F5A` | 说明文字（中棕色） |
| **文字三** | `#B8A396` | 辅助文字（浅棕色） |

### 图标系统

已使用的图标类型：
- `CALENDAR` - 日历/Logo
- `TASK` - 任务
- `BILL` - 记账
- `CHAT` - 对话
- `SETTINGS` - 设置
- `LOCK` - 登录
- `INFO` - 信息提示
- `ADD` - 添加
- `CLOSE` - 关闭
- `SEARCH` - 搜索
- `LEAF` - 节气
- `STAR` - 星座

### 动画系统

| 动画类型 | 时长 | 应用场景 |
|----------|------|----------|
| **快速** | 150ms | 按钮反馈、状态切换 |
| **正常** | 250ms | 页面元素淡入、卡片动画 |
| **慢速** | 350ms | 页面转场、复杂动画 |

### 间距系统

| 级别 | 值 | 应用场景 |
|------|-----|----------|
| **XS** | 4px | 极小间距、图标边距 |
| **SM** | 8px | 小间距、行内元素 |
| **MD** | 16px | 中等间距、卡片内边距 |
| **LG** | 24px | 大间距、区块间距 |
| **XL** | 32px | 超大间距、页面边距 |
| **XXL** | 48px | 极大间距、特殊布局 |

## 📝 优化规范

### 必须遵循的原则

1. **图标使用**
   - ❌ 不使用 emoji
   - ✅ 使用 IconComponent
   - ✅ 统一图标大小和颜色

2. **颜色使用**
   - ❌ 不使用硬编码颜色
   - ✅ 使用 Constants.COLOR_*
   - ✅ 确保对比度 ≥ 4.5:1

3. **间距使用**
   - ❌ 不使用魔法数字
   - ✅ 使用 Constants.SPACING_*
   - ✅ 保持视觉节奏

4. **动画使用**
   - ❌ 不使用过慢动画（>500ms）
   - ✅ 使用 AnimationUtils
   - ✅ 添加交互反馈

5. **交互反馈**
   - ❌ 不忽略按压状态
   - ✅ 添加 stateEffect
   - ✅ 添加 hoverEffect（如适用）
